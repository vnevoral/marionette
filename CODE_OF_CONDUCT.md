# Code of conduct

Marionette adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in the project — in issues,
pull requests, discussions and reviews — is expected to follow it.

In short: be respectful and constructive, assume good intent, and focus on
the work rather than on people. Harassment, insults and personal attacks
are not tolerated.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@vnevoral](https://github.com/vnevoral), through the contact on the GitHub
profile, or through
[a private security advisory](https://github.com/vnevoral/marionette/security/advisories/new)
if no other channel is available. Reports are handled confidentially.

The maintainer may edit or remove comments, commits, issues and pull
requests, and may block contributors who violate the code of conduct, as
described in the Contributor Covenant enforcement guidelines.
